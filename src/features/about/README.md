# About Feature

Sección de información sobre SwiftDrop, incluyendo:

- **AboutHero**: Sección hero con presentación principal
- **MissionSection**: Tarjetas de misión, visión y valores
- **StorySection**: Historia detallada de SwiftDrop
- **TeamSection**: Presentación del equipo fundador y líderes
- **TechSection**: Tecnologías utilizadas
- **ImpactSection**: Estadísticas de impacto

## Componentes

- `AboutPage`: Componente principal que agrupa todas las secciones
- Todas las secciones usan Framer Motion para animaciones
- Diseño responsivo con Tailwind CSS
- Integración con fuentes personalizadas del proyecto
